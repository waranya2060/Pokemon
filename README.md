# Pokémon Team Builder 

โปรเจ็กต์นี้คือแอปสำหรับเลือกโปเกมอน สร้างทีม และบันทึกทีมไว้ในเครื่อง โดยดึงข้อมูล/รูปภาพจาก Pokeapi และใช้ GetStorage สำหรับจัดเก็บข้อมูลแบบโลคัล

- ค้นหา/เลือกโปเกมอนจาก API (PokeAPI)
- แสดงรูปโปเกมอนจากสปไรต์สาธารณะ
- สร้างทีม ตั้งชื่อทีม และบันทึกลงเครื่องด้วย get_storage
- เรียกดูทีมที่เคยบันทึกไว้ และโหลดกลับมาแก้ไขได้
- UI เรียบง่าย (Material + GetX)

 ข้อกำหนด (Requirements)
โปรเจ็กต์ตั้งค่าจาก `pubspec.yaml` ไว้ดังนี้
- Dart SDK: `>= 3.8.0 < 4.0.0`
- Flutter: ช่องทางเสถียร (stable) ที่รองรับ Dart 3.8+
- แพ็กเกจหลัก 
  - http: ^1.1.0 (เรียก REST API)  
  - get_storage: ^2.1.1 (จัดเก็บข้อมูลโลคัล)  
  - get: ^4.6.5 (โครงสร้าง/นำทางแบบ GetX)  
  - cupertino_icons: ^1.0.8

วิธีรัน  
1) ตรวจสอบสภาพแวดล้อม
   
   flutter doctor
   
2) เข้าพาธโปรเจ็กต์หลัก
   
   cd pokemon/pokemon
   
3) ดึงแพ็กเกจ
   
   flutter pub get
   
5) รันแอป 
- คำสั่ง:
 
  flutter run
